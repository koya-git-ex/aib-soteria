# SOTERIA AI Platform — Vercel static site

This is a static website. It has no build step, backend, API key, or environment variables.
The logo is embedded in `index.html`.

## Deploy with GitHub + Vercel

1. Create a GitHub repository and upload `index.html`, `vercel.json`, and this README at the repository root.
2. In Vercel, choose **Add New → Project**, import the repository, and deploy.
3. Keep the framework preset as **Other**. Leave Build Command and Output Directory empty/default for a static site.
4. Open the generated URL and test the navigation and interactive demo.

All displayed company data is demonstration data. External search opens Google/Bing in a new tab; it does not fetch or summarize pages inside the site.
